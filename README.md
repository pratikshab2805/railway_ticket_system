# railway_ticket_system
# Railway Ticket Booking System

## Description

A modular interactive command-line Railway Ticket Booking System
developed in Python.

The system supports:

- Route selection
- Distance-based fare calculation
- Multiple passengers
- Senior citizen discounts
- Train type premiums
- Travel class premiums
- Baggage allowance and excess baggage fees
- Promotional discounts
- Final booking summary
