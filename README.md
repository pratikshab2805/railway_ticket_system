# Railway Ticket Booking System

## Description

This project is a modular and interactive command-line Railway
Ticket Booking System developed in Python.

The system supports:

- Passenger information intake
- Route selection
- Distance-based fare calculation
- Senior citizen discount
- Train type premium
- Travel class premium
- Baggage allowance checking
- Excess baggage charges
- Promotional discounts
- Travel time calculation
- Final booking summary
